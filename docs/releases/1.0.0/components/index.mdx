> Documents saga a2ui **1.0.0** (stable). This catalog is generated from the package manifests and entry points at source revision [`15591e3`](https://github.com/MachineWisdomAI/saga-a2ui/tree/15591e35b1287486ea789f49cd5ead998ed03b89). Every component the SDK documents at this release is listed here or in the exclusions below. A row names only exports found in the source at the pinned revision.

| Component | Renderers | Summary |
| --- | --- | --- |
| [FaithfulCard](/docs/releases/1.0.0/components/faithful-card) | Lit, React | A card that shows Markdown from an untrusted result under a content policy, with link and image consent, for answers that need their sources and limits kept visible. |

| [SagaAttribution](/docs/releases/1.0.0/components/saga-attribution) | React | A removable one-line credit, Built with saga a2ui, for an application with its own catalog. It carries no card, Markdown parser or components package. |

## Not in the catalog

- **Typed surfaces.** `Surface`, `openSurface` and the stack's `defineSurface` compose and bind a surface. They are APIs, not components an application places in a layout.
- **Layout and basic components.** Row, Column, List and the other basic components come from the upstream A2UI v0.9 catalog that the renderer packages forward (`basicCatalog`, `ColumnApi`, `ListApi`, `RowApi`). The SDK does not document them as its own.
- **Lynx.** No Lynx package exists. The packages guide records that the Lynx delivery chain was retired.
