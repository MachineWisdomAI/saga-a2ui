The saga a2ui React stack **1.0.1** exposes the server entry points listed below. Use this version's package exports when choosing imports.

Package version: **1.0.1 (stable)**. [Pinned SDK source](https://github.com/MachineWisdomAI/saga-a2ui/tree/a9633b399cf7318ecd934aaef192263119373692/packages/react-mcp-stack). [Published package](https://www.npmjs.com/package/@saga-a2ui/react-mcp-stack/v/1.0.1).

This release exports `/server`, `/server/http`, and `/server/node`.

| Import                                   | Package source               |
| ---------------------------------------- | ---------------------------- |
| `@saga-a2ui/react-mcp-stack/server`      | `./src/server/index.ts`      |
| `@saga-a2ui/react-mcp-stack/server/http` | `./src/server/http/index.ts` |
| `@saga-a2ui/react-mcp-stack/server/node` | `./src/server/node/index.ts` |

These are server-side imports. Compose the server separately from browser view code. The application still supplies the framework peers named in [installation](/docs/releases/1.0.0/installation).
