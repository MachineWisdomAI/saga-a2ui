A card that shows Markdown from an untrusted result under a content policy, with link and image consent, for answers that need their sources and limits kept visible.

Renderers: Lit and React.

## Evidence and limits

- Local host-fixture tests render the card in both renderers, directly and through each stack's start. The guide calls this a local fixture result, not acceptance by any actual host. ([Styling qualification](/docs/releases/0.7.6/guides/faithful-card-styling#qualification))
- The dated host observations used standalone probes that did not use SAGA's React adapter or MCP adapter, so they do not qualify this component in a host. ([Host observations](/docs/releases/0.7.6/guides/host-compatibility-observations))
- Package exports and tests establish a contract. Acceptance in a named assistant host is recorded only where a page above says so.
