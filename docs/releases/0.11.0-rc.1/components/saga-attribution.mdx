## Static demonstration

The credit rendered in an application's own footer, using the host link seam. It is a copy of lines from [`docs/react-consumers.md`](https://github.com/MachineWisdomAI/saga-a2ui/blob/fb4126cc5a9ac2e7f9cd916c377d24b237d00bb8/docs/react-consumers.md) at the pinned revision, not a live rendering.

```tsx
import {SagaAttribution, startA2uiView, type HostLinks} from '@saga-a2ui/react-mcp-stack';
import '@saga-a2ui/react-mcp-stack/attribution.css';

let links: HostLinks | undefined;
startA2uiView({
  // ...
  actions: (host) => {
    links = host.links; // asks the host to open a link; ends with the view
    return undefined;
  },
});

// Wherever the application renders its footer:
<footer><SagaAttribution links={links} /></footer>
```
