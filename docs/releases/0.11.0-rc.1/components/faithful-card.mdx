Renderers: Lit and React.

## Evidence and limits

- Local host-fixture tests render the card in both renderers, directly and through each stack's start. The guide calls this a local fixture result, not acceptance by any actual host. ([Styling qualification](/docs/releases/0.11.0-rc.1/guides/faithful-card-styling#qualification))
- The recorded answer-card flows were observed in ChatGPT web and Claude web, and the Ansari answer-card flow in the Alexa+ simulator. The guide says these are observations of particular flows, not a complete renderer, device or host-version matrix. ([Host compatibility](/docs/releases/0.11.0-rc.1/guides/host-compatibility))
- Package exports and tests establish a contract. Acceptance in a named assistant host is recorded only where a page above says so.
