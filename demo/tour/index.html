Explore the notes workflow: allowed, denied and obsolete actions

This is the notes example from the SAGA demonstration, running its real view, action definitions and renderer in your browser. There is no backend: a small simulated server in this page answers the view’s three tool calls from synthetic data and from the situation you choose. Every scenario links to the source it uses.

  • Real here: the notes view, its layout messages, its action definitions, the action runtime and the renderer.
  • Simulated here: who is asking, the session check, the server’s decision and its backend. Their answers are local data you select.
  • Not in this tour: episode descriptions and protected Play. They need the demonstration’s real server, so they are not offered here; run the local demonstration to try them.

        What this tour does not show

        • No real authentication, OAuth flow or identity provider, and no run in ChatGPT, Claude or Alexa+. The host here is a local stand-in, not an assistant host.
        • No protected media, no Patreon access and no playback. This tour plays nothing.
        • React has bounded evidence: direct action attachment and the notes application in a local fixture host. It is not renderer parity, and there is no React starter, template or CLI pair.
        • The SDK is an unpublished candidate. The packages are private and this page is built from locally packed candidate tarballs, not from a registry.
