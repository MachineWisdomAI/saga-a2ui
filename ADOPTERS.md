# Adopters

Applications using saga a2ui, with the scope and status of their integration.

| Application | Use | Status |
| --- | --- | --- |
| Ansari Faithful Answers | Presents an Ansari answer and its source attribution using saga a2ui's FaithfulCard and MCP Apps integration. Developed as a contribution back to the Ansari community. | Staging and export preparation. Public package installation and acceptance into the destination Ansari repository remain pending; this is not a claim of a completed upstream adoption. See the [integration design and acceptance boundaries](blueprints/features/ansari_adoption.blueprint.md). |

The [podcast and notes demo](demo/lit-node/README.md) is maintained in this repository and uses synthetic data. It is an example, not an independent adopter. Patreon, Headspace and assistant hosts are not listed as adopters or endorsers.

## Add your application

Open a small pull request with its name, a public project or demo link if available, a sentence about how it uses saga a2ui, and its current status (experiment, staging or production). Only list an application you are authorized to represent. An entry is informational and does not imply endorsement or commercial support. No email address is required.
