# Building with Saga

## IASER — Ansari

[IASER](https://iaser.ai/) is the team behind [Ansari](https://askansari.ai), an AI assistant for questions about Islam. The [Ansari integration uses Saga](https://github.com/iaser-ai/ansari) to bring answers and their sources into assistant conversations through MCP Apps. Saga’s [FaithfulCard component](docs/react-consumers.md) presents the Markdown answer in a styled card, preserving its formatting and source attribution. It renders the answer supplied by Ansari directly, so the host LLM does not have to paraphrase it for display.
